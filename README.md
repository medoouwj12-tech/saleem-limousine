# سليم ليموزين ورحلات

موقع تعريفي وحجز لخدمات سليم ليموزين، بواجهة عربية وإنجليزية، وتصميم متجاوب، وأساطيل وخدمات وحجوزات مباشرة عبر واتساب.

## التشغيل

افتح `index.html` في المتصفح. يستخدم الموقع Tailwind CSS وFont Awesome وGoogle Fonts عبر CDN، لذلك يلزم اتصال بالإنترنت لتحميل التنسيقات والخطوط الخارجية.
